소개팅앱을 만들거야, 아래 내용 확인해서 필요하면 스킬 활용해서 문서 잘 만들어줘 특히 디자인과 소개팅앱 기본 시스템 작동을 위해 디테일한 안내 팝업이나 필수로 들어가야되는 기능들은 너가 능동적으로 추가해서 앱이 정상 구현되게 문서 작성해줘
모바일 웹 버전으로 만들어서 앱으로 패키징할거야
앱으로 사용할거니까 디자인 기획하거나 서비스 기획할때 앱임을 감안해서 네비게이션바에 핵심 카테고리들 넣어서 디자인 구현하고, 기존에 소개팅앱들 디자인 참고해줘

우리 소기탱앱은 돌싱(이혼남녀)들을 위한 서비스야, 그러니까 전체적으로 30~50이 타겟층이고 신뢰도를 줄수있는 색감과 디자인으로만들어줘,

남녀 구분되어 가입하고, 가입할때 이혼 몇번째인지 입력, 0번도 가입 가능, 아이유무 몇명인지 입력, 그리고 이메일 또는 sns로 간편가입, 사진 등록(3장이상), 지역선택, 본인인증 할거야.

가입 할때나 가입 후에 배찌를 통해 인증 시스템을 넣을거야, 인서울 대학, 대기업, 연봉 5천이상, 1억이상, 자산 1억이상 3억이상 5억이상, 이런식으로 골드스푼 참고해서 신용할 수 있는 배찌 종류 넣을거야. 그리고 이거는 서류 첨부하면 관리자가 확인 후 승인해줄거야 그러면 배찌가 부여되서 다른 사람들이 볼 수있어, 배찌마다 필요한 서류는 어드민에서 관리자가 텍스트로 요청하도록 해줘 그래서 그때그때 간단히 수정 하도록 해줘

지역과 나이 기반으로 해당 지역 나이차이 덜나는 사람들로 하루에 2번 프로필 카드가 발행되게 해줘, 아침 9시 오후 6시 한명씩 두번, 프로필은 미리보기로 사진하나와 기본적인 정보만 보여, 상세페이지 접속시 본인소개같은 내용들이 조금 더 디테일하게 보이는데 사진은 하나만 보여, 더많은 사진을 보려면 프로필 오픈 필요 (100포인트)
호감보내기, 매칭 신청, 소개팅 신청 3가지 버튼이 있어
호감 보내기도 200포인트, 매칭 신청은 300포인트, 소개팅 신청은 500포인트
호감 보내기는 상대방에게 도착하면 푸쉬알림, 그리고 호감을 받으면 본인한데 알림이 와서 보낸사람 프로필 볼수있음, 상대방도 호감 보내면 양쪽이 호감을 보냈다고 표시됨,

매칭 신청하면 동일하게 상대방한데 뜸, 상대방도 매칭 승인 버튼 생김 매칭 승인시 300포인트 발생, 양측이 매칭을 승인하면 번호 확인 버튼이 생김, 양측 누구나 할 수있고 번호 확인 비용은 500포인트고 상대방 번호가 나한데 보임, 상대방이 번호 확인을 하고나면 나한데 상대방이 번호 확인했다고 표시, 소개팅 신청도 동일하게 상대방한데 알림 상대방도 소개팅 신청 승인에 500포인트 발생, 양측이 승인하고나면 번호 확인 버튼 생성 동일하게 500포인트 소모,

호감 = 단순히 서로 호감이 있음을 저렴하게 확인하는 역할
매칭신청 = 서로 번호 공개
소개팅 신청 = 서로 번호 공개 + 안내를 통해 서로 바로 만나기로 동의한 사람이라는 의미

+ 메시지 보내기 버튼 있음, 메시지 보내기는 500 포인트 소모, 본인이 하고싶은 이야기 메시지 전달 가능. 상대방은 메시지 확인 가능

포인트는 10원에 1포인트야. 충전 형태로 포인트 충전해서 사용
1만원 단위, 00원 결제시 00원 충전 이런 이벤트는 관리자가 어드민에서 여러개 만들고 수정하면서 운영할수있게 어드민에 구현

비용이 발생하는 각 항목도 어드민에 구현해서 관리자가 실시간 수정 가능하게 구현

본인이 봤던 카드들 리스트는 한곳에 저장되고 호감 보낸, 받은 사람, 번호 확인 보낸 받은 사람, 소개팅 신청 한, 받은 사람, 메시지 보낸, 받은 사람은 마크로 표시하고 필터로 그런 유저들만 확인 가능, 카드리스트는 10일 후 자동 삭제됨

대분류 카테고리로 커뮤니티 기능이 있음,
자유 게시판, 번개 게시판 2개 운영
자유 게시판 - 검색어 필터로 자유롭게 글 작성하고 검색 / 글 작성자 위치 표시 / 글 작성자 프로필 보려면 200포인트 소모, 그 뒤 프로필 상세페이지에서는 위와 동일하게 프로세스 진행, 프로필 한번 보면 카드 리스트로 들어가서 10일간 거기 있음

번개 게시판 - 주제 선정 + 자유롭게 글 사진 작성, 검색어 필터, 남녀 필터, 주제 필터, 주제는 와인한잔, 소주한잔, 맥주한잔, 커피한잔, 드라이브, 산책, 저녁식사, 점심식사


이러한 서비스 만들려는데 이 서비스 최대한 자세하게 설명 기획내용 작성해줘 이런 서버스에 필요한 화면이나 기능들 최대한 넣어서 오래걸려도 문서 디테일하게 만들어줘, 기본적으로 앱으로 사용할거니까 기획해서 넣어줘
