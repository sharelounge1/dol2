## 1. 인증 & 온보딩

### 1.1 스플래시 화면 (SplashScreen)

**화면 ID**: AUTH-001
**라우트**: `/splash`

**주요 기능**:
- 앱 로고 표시
- 로딩 애니메이션
- 자동 로그인 체크
- 온보딩 완료 여부 체크

**프로세스**:
1. 앱 실행 시 2초간 스플래시 화면 표시
2. 로컬 스토리지에서 토큰 확인
3. 토큰이 있으면 → 자동 로그인 → HomeScreen
4. 토큰이 없고 온보딩 미완료 → OnboardingScreen
5. 토큰이 없고 온보딩 완료 → LoginScreen

**UI 요소**:
- 앱 로고 (중앙)
- 앱 이름 "재연(再緣)"
- 로딩 인디케이터

---

### 1.2 온보딩 화면 (OnboardingScreen)

**화면 ID**: AUTH-002
**라우트**: `/onboarding`

**주요 기능**:
- 앱 소개 슬라이드 (3-4개)
- 주요 기능 안내
- 시작하기 버튼

**슬라이드 내용**:
1. **슬라이드 1**: "신뢰할 수 있는 돌싱 매칭"
   - 배찌 인증 시스템 소개
   - 안전한 매칭 강조

2. **슬라이드 2**: "하루 2번, 특별한 인연"
   - 오전 9시, 오후 6시 카드 발행
   - 지역/나이 기반 매칭

3. **슬라이드 3**: "단계별 관계 발전"
   - 호감 → 매칭 → 소개팅 → 번호 공개
   - 포인트 시스템 소개

4. **슬라이드 4**: "활발한 커뮤니티"
   - 자유게시판, 번개게시판 소개

**UI 요소**:
- 슬라이드 이미지/일러스트
- 페이지 인디케이터 (점)
- "건너뛰기" 버튼 (우측 상단)
- "다음" 버튼
- "시작하기" 버튼 (마지막 슬라이드)

**프로세스**:
1. 좌우 스와이프로 슬라이드 이동
2. "건너뛰기" 클릭 → LoginScreen
3. 마지막 슬라이드에서 "시작하기" → LoginScreen
4. 온보딩 완료 플래그 로컬 저장

---

### 1.3 로그인 화면 (LoginScreen)

**화면 ID**: AUTH-003
**라우트**: `/login`

**주요 기능**:
- 이메일 로그인
- SNS 간편 로그인 (카카오, 네이버, 구글)
- 비밀번호 찾기
- 회원가입 링크

**UI 요소**:
- 앱 로고
- 이메일 입력 필드
- 비밀번호 입력 필드
- "로그인" 버튼
- "비밀번호 찾기" 링크
- 구분선 "또는 SNS로 시작하기"
- 카카오 로그인 버튼
- 네이버 로그인 버튼
- 구글 로그인 버튼
- "아직 회원이 아니신가요? 회원가입" 링크

**프로세스**:
1. 이메일/비밀번호 입력
2. 유효성 검사
   - 이메일 형식 확인
   - 비밀번호 6자 이상
3. "로그인" 버튼 클릭
4. API 호출 → 토큰 저장 → HomeScreen
5. SNS 로그인 클릭 → 해당 Provider OAuth → 자동 가입/로그인

**에러 처리**:
- 이메일/비밀번호 불일치: "이메일 또는 비밀번호가 올바르지 않습니다"
- 계정 정지: "이용이 정지된 계정입니다. 고객센터에 문의하세요"
- 네트워크 에러: "네트워크 연결을 확인해주세요"

### 1.4 회원가입 - 가입 방식 선택 (SignupMethodScreen)

**화면 ID**: AUTH-004
**라우트**: `/signup`

**주요 기능**:
- 가입 방식 선택
- 약관 동의

**UI 요소**:
- 타이틀 "재연에 오신 것을 환영합니다"
- 서브타이틀 "가입 방식을 선택해주세요"
- 이메일로 가입 버튼
- 카카오 간편가입 버튼
- 네이버 간편가입 버튼
- 구글 간편가입 버튼
- 약관 동의 체크박스
  - 전체 동의
  - (필수) 이용약관 동의
  - (필수) 개인정보처리방침 동의
  - (필수) 위치기반서비스 이용약관 동의

**프로세스**:

### 1.5 이메일 회원가입 (EmailSignupScreen)

**화면 ID**: AUTH-005
**라우트**: `/signup/email`

**주요 기능**:
- 이메일/비밀번호 입력
- 이메일 중복 확인
- 비밀번호 강도 체크

**UI 요소**:
- 이메일 입력 필드
  - 중복 확인 버튼
- 비밀번호 입력 필드
  - 비밀번호 표시/숨김 토글
  - 강도 인디케이터 (약함/보통/강함)
- 비밀번호 확인 입력 필드
- "다음" 버튼

**유효성 검사**:
- 이메일 형식 검증
- 이메일 중복 체크
- 비밀번호 8자 이상, 영문+숫자+특수문자 조합
- 비밀번호 확인 일치

**프로세스**:
1. 이메일 입력 → "중복 확인" 클릭
2. 비밀번호 입력 → 강도 표시
3. 비밀번호 확인 입력 → 일치 여부 표시
4. "다음" 클릭 → ProfileBasicScreen

### 1.6 프로필 기본정보 (ProfileBasicScreen)

**화면 ID**: AUTH-006
**라우트**: `/signup/profile-basic`

**주요 기능**:
- 성별, 생년월일, 이혼 횟수, 자녀, 지역 입력

**UI 요소**:
- 진행률 표시 (1/5)
- 타이틀 "기본 정보를 알려주세요"
- 성별 선택 (남성/여성)
- 생년월일 선택 (달력)
- 이혼 횟수 선택 (0, 1, 2, 3회 이상)
  - 0회 선택 시: "미혼자도 환영합니다" 안내
- 자녀 유무 선택 (없음/있음)
  - 있음 선택 시: 자녀 수 선택 (1~5명 이상)
- 지역 선택 (시/도 → 구/군)
- "다음" 버튼

**프로세스**:
1. 모든 필드 입력 완료
2. "다음" 클릭 → ProfilePhotosScreen

### 1.7 프로필 사진 등록 (ProfilePhotosScreen)

**화면 ID**: AUTH-007
**라우트**: `/signup/profile-photos`

**주요 기능**:
- 사진 등록 (최소 3장, 최대 10장)
- 사진 크롭/회전
- 대표 사진 설정

**UI 요소**:
- 진행률 표시 (2/5)
- 타이틀 "매력적인 사진을 등록해주세요"
- 서브타이틀 "최소 3장, 최대 10장"
- 사진 그리드 (3열)
  - 첫 번째: "대표 사진" 라벨
  - 빈 슬롯: "+" 버튼
  - 등록된 사진: 썸네일 + 삭제 버튼
- "사진 추가" 버튼
- "다음" 버튼

**프로세스**:
1. "사진 추가" 클릭 → 갤러리/카메라 선택
2. 사진 선택 → 크롭 화면 → 저장
3. 사진이 3장 미만: "다음" 버튼 비활성화
4. 사진이 3장 이상: "다음" 버튼 활성화
5. 드래그로 순서 변경 가능
6. "다음" 클릭 → 이미지 압축 → 업로드 → ProfileDetailsScreen

**제약사항**:
- 최대 파일 크기: 1MB (압축 자동 처리)
- 지원 포맷: JPG, PNG
- 최소 해상도: 800x600

## 2. 홈 & 매칭

### 2.1 홈 화면 (HomeScreen)

**화면 ID**: HOME-001
**라우트**: `/home`

**주요 기능**:
- 오늘의 카드 요약
- 받은 액션 요약 (호감, 매칭, 소개팅)
- 포인트 잔액 표시
- 빠른 메뉴

**UI 요소**:
- **헤더**
  - 앱 로고
  - 알림 아이콘 (뱃지: 읽지 않은 알림 수)
  - 포인트 표시 (예: "2,500P" + 충전 버튼)

- **오늘의 카드 섹션**
  - 타이틀 "오늘의 인연"
  - 오전 카드 (9시 발행)
    - 발행 전: "오전 9시에 발행됩니다" + 타이머
    - 발행 후: 프로필 카드 미리보기
  - 오후 카드 (18시 발행)
    - 발행 전: "오후 6시에 발행됩니다" + 타이머
    - 발행 후: 프로필 카드 미리보기
  - "전체 보기" 버튼 → TodayCardsScreen

- **받은 액션 섹션**
  - 타이틀 "받은 액션"
  - 호감 받음 (숫자 뱃지)
  - 매칭 신청 받음 (숫자 뱃지)
  - 소개팅 신청 받음 (숫자 뱃지)
  - 메시지 받음 (숫자 뱃지)
  - "전체 보기" → ReceivedActionsScreen

- **카드 히스토리**
  - 타이틀 "최근 본 카드"
  - 최근 3개 프로필 썸네일
  - "전체 보기" → CardHistoryScreen

- **빠른 메뉴**
  - 배찌 신청
  - 포인트 충전
  - 고객센터

**하단 네비게이션**:
- 홈 (활성화)
- 커뮤니티
- 알림
- 마이페이지

### 2.3 프로필 상세 (ProfileDetailScreen)

**화면 ID**: HOME-003
**라우트**: `/home/profile/:userId`

**주요 기능**:
- 프로필 단계별 공개
- 매칭 액션 (호감, 매칭, 소개팅, 메시지)

**UI 구조**:

**단계 1: 미리보기 (무료)**
- 대표 사진 1장 (블러 처리)
- 기본 정보
  - 닉네임 (마스킹: 김**)
  - 나이, 성별
  - 지역 (구/군까지)
  - 이혼 횟수
  - 자녀 유무/수
- 배찌 (아이콘만)
- "프로필 오픈 (100P)" 버튼

**단계 2: 프로필 오픈 후 (100P)**
- 대표 사진 1장 (선명)
- 상세 정보
  - 자기소개
  - 직업
  - 키, 체형
  - 학력
