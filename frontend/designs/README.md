# 재연(再緣) 홈화면 디자인 컨셉 7종

> 돌싱(이혼남녀)을 위한 프리미엄 소개팅 앱 메인 화면 디자인 시안

---

## 📋 개요

이 디렉토리는 재연(再緣) 앱의 홈화면에 대한 **7가지 서로 다른 디자인 컨셉**을 담고 있습니다.
각 컨셉은 색상뿐만 아니라 **UI 구조, 인터랙션 방식, 타겟 사용자의 감성**까지 완전히 다르게 기획되었습니다.

💡 **컨셉 6, 7은 실제 경쟁 앱(골드스푼, 스카이피플)을 참고하여 제작되었습니다.**

### 타겟 사용자
- **연령대**: 30~50대
- **특성**: 이혼 경험이 있는 성숙한 성인
- **니즈**: 신뢰할 수 있고, 진지한 만남을 원함
- **기술 수준**: 중급 이상의 모바일 사용 능력

## 🎨 디자인 컨셉 목록

### 1️⃣ 컨셉 1: 프리미엄 럭셔리 (Premium Luxury)

**📁 파일**: `concept1-premium/index.html`

**🎯 컨셉 설명**
- 고급스럽고 세련된 VIP 회원 전용 서비스 느낌
- 어두운 배경에 골드 악센트로 프리미엄 감성 극대화
- 배찌 시스템을 전면에 내세워 신뢰도 강조

**🎨 디자인 특징**
- **색상**: 다크 그레이(#1a1a1a) + 골드(#D4AF37) + 화이트
- **레이아웃**: 대형 프로필 카드 + 그라디언트 오버레이
- **인터랙션**: 호버 시 카드 확대, 배찌 반짝임 효과
- **아이콘**: VIP 왕관, 다이아몬드 배찌

**👥 타겟**
- 경제력이 있는 고소득 사용자
- 프리미엄 서비스를 선호하는 층
- 배찌를 많이 보유한 신뢰도 높은 회원

**💡 주요 기능**
```
✅ 실시간 타이머 (다음 카드 오픈까지)
✅ 배찌 등급별 필터링
✅ 대형 프로필 이미지 (얼굴 중심)
✅ 호감/매칭/소개팅 신청 원클릭
✅ 포인트 잔액 상단 고정
```

- **레이아웃**: 카드 리스트형 + 통계 바

- **타이포그래피**: 고딕 산세리프, 큰 폰트

**👥 타겟**
- 간결함을 선호하는 실용주의자
- 정보를 빠르게 파악하고 싶은 바쁜 직장인
- 30대 후반~40대 초반 연령층

**💡 주요 기능**
```
✅ 통계 대시보드 (호감/매칭/신청 현황)
✅ 리스트형 프로필 카드
✅ 받은 액션 분리 표시
```

**💡 주요 기능**

## 🛠️ 기술 스택

각 디자인은 순수 HTML/CSS/JavaScript로 제작되었습니다.

```
HTML5          # 시맨틱 마크업
CSS3           # Grid, Flexbox, Animation
Vanilla JS     # 인터랙션 로직
```

**사용된 주요 기술**
- CSS Grid / Flexbox 레이아웃
- CSS Transitions / Animations
- JavaScript Event Listeners
- Touch Events (모바일 제스처)
- LocalStorage (타이머 상태 저장)
- Date API (실시간 타이머)
